# Network Manager v0.6.3

这是一次三端性能与稳定性补丁版本，不改变跨设备配置格式和现有分流规则行为。

## 性能与稳定性

- Windows 将端口探测和控制器健康检查移出界面线程，避免网络异常时卡住窗口。
- Windows 在窗口隐藏或最小化时降低后台轮询频率，并缓存未变化的状态，减少 CPU 与样式重绘开销。
- WebGUI 根据页面可见性和任务状态自适应刷新；节点、规则、订阅、日志与图表只在数据变化时更新。
- 本地 WebGUI 启用 HTTP/1.1 长连接，并忽略客户端正常断开产生的无效异常日志。
- Android 仅在 VPN 接管运行时采样流量，空闲状态不再持续写入相同数据，降低 Compose 重组与后台耗电。
- Linux 无界面服务在停止接管时使用低频监控，并避免重复清空流量状态和同步端口探测。

## 发布产物

- `NetworkManager-Setup-x64-v0.6.3.exe`：Windows x64 正式安装包。
- `NetworkManager-Android-v0.6.3.apk`：Android 正式签名 APK。
- `NetworkManager-Linux-amd64-v0.6.3.tar.gz`：Linux amd64 无界面 WebGUI 服务包。
- `NetworkManager-Linux-arm64-v0.6.3.tar.gz`：Linux arm64 无界面 WebGUI 服务包。
- `SHA256SUMS.txt`：上述正式产物的 SHA-256 校验值。
- GitHub 自动生成的源码 `zip` 和 `tar.gz` 快照，对应同一发布提交与标签。

Windows 安装程序尚未配置商业代码签名证书，系统可能显示“未知发布者”。Android APK 使用项目正式发布密钥签名，可覆盖安装此前正式版本。
