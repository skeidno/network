# Network Manager v0.4.0

Windows 与 Android 首个同步版本。

## 源码记录

- 本次发布的完整源码固定在 Git 标签 `v0.4.0`，与 Windows、Android 成品使用同一提交。
- GitHub Release 页面同时提供自动生成的 `Source code (zip)` 与 `Source code (tar.gz)`。
- 仓库已按 `apps/windows`、`apps/android`、`apps/macos`、`apps/ios` 记录各平台现状和后续入口。

## 主要更新

- 新增智能节点模式，周期检测全部候选节点并在明显变慢或失效时自动切换。
- 修复 Windows TUN 重复启动、配置切换和快速页面切换可能造成的卡死或崩溃。
- 普通配置修改使用 Mihomo 热加载，不再反复重建 TUN 网卡。
- 新增 TUN 就绪检查、控制端口健康检查及三次退避自动恢复。
- 节点支持单独测速、并发单卡测速、批量测速以及 Error 节点一键清理。
- 删除的订阅节点可通过刷新原订阅恢复，测速结果按低延迟优先、Error 置后。
- 内网、局域网、回环、链路本地和保留地址始终直连，不受全局或保底规则影响。
- Windows 与 Android 支持同格式配置导入导出，SSH 与本地端口不会跨设备导出。
- Android 原生客户端加入系统 VPN 接管、订阅、规则、智能节点、流量监控和节点管理。
- Windows 构建自动创建桌面快捷方式。

## 下载

- Windows：下载 `NetworkManager-Windows-x64-v0.4.0.zip`，完整解压后运行 `NetworkManager.exe`。
- Android：下载并安装 `NetworkManager-Android-v0.4.0.apk`，首次接管时允许系统 VPN 权限。
- `SHA256SUMS.txt` 包含两个发布文件的 SHA-256 校验值。

## 发布验证

- Python：48 项自动化测试通过，Ruff 与 Web 前端语法检查通过。
- Windows：管理员模式启动、TUN 接管、67 条内置规则、节点加载及 WebGUI 冒烟测试通过。
- Android：5 项模拟器设备测试通过；正式签名 APK 冷启动、VPN 建立、实际流量与停止清理均通过。

Windows TUN 需要管理员权限。Android 最低版本为 Android 8.0（API 26）。
