# v0.6.17

## 新增：内置规则组（常用国内站点 / 常用海外站点）

以前想让「微信、淘宝、支付宝、飞书、抖音」这些国内站点一律直连，只能一条条
手填域名。现在这两个组内置了，整组开关、整组换出口、整组编辑域名：

| 分组 | 默认出口 | 说明 |
| --- | --- | --- |
| 常用国内站点 | 直连 | 腾讯系、阿里系、字节系、百度系、京东美团携程、B 站微博、网易搜狐、爱奇艺优酷、知乎小红书、WPS、华为小米、Gitee/CSDN、银行与运营商、顺丰等 |
| 常用海外站点 | 代理 | Discord、Telegram、X、YouTube、Google、OpenAI、Claude、GitHub、Netflix、Spotify、维基百科、Notion 等 |

只收常用的，偏僻域名一律不进（之前那一版塞得太满，这次砍回核心）。
**不需要就整组关掉**，关掉后组内规则不再下发，不是「留着但不生效」。

组内判定按组 id 而不是按出口：你把整组换成别的出口后，它仍然是一整组，
不会散成几百条单条规则。

## 修复：流量曲线不再恒为 0

侧边栏那条速率曲线从 v0.6.3 起就是写死的 0 —— 曲线贴着网格线，看着像「图表
没了」。现在接内核的 `/connections`，用两次累计值差分算速率，连接数也是真的。

注意第一次采样只是记基线、不出速率，所以刚接管的一两秒内显示 0 是正常的。

## 修复：测速改问内核，不再只用握手冒充可用性

之前测速只做一次 TCP 握手：端口能连上就算通过。对代理商批发的节点来说端口
一律开着、握手毫秒级成功，可一发真实请求就被掐断 —— 于是界面显示「全通」，
实际一个都代理不出去。

现在内核在跑就问内核的延迟接口，走的是节点自己的完整链路（建隧道 → 认证 →
取回响应），**统一中转也天然包含在内**。没接管时才退回握手。

界面上经过中转的节点会带一个「经中转」标记。

## 修复：统一中转改成本机端口安全

- 改成全局统一中转（一个开关 + 一个中转节点），砍掉原来的逐节点前置：
  两套混着用会出现「同一个列表里有的走中转、有的不走」，最难排查。
- **落在本机回环的节点不再被串进中转链**：中转在远端，它连的是自己那台机器
  的 127.0.0.1，永远到不了我们本机这个端口。
- 开关和选择不再互相阻塞，中转节点下拉恢复可选。

## 修复：切换节点真正生效

之前切换节点只写盘、不通知内核，界面换了、流量还走老节点。现在切换会真的
应用到内核。

## Android 端

- **新增统一中转**：设置页「统一中转」一个开关 + 中转节点选择，语义与桌面端
  一致（中转自己不走中转、本机回环节点不挂中转、没选节点时开关禁用）。
  之前 Android 端完全没有这个功能。
- **修掉一个静默故障**：节点配置里如果是 sing-box 原生格式的 `tls`（嵌套对象
  而不是 `tls: true`），整段 TLS/Reality 会被无声丢弃 —— 不报错、内核起得来、
  测速一律 Error，从日志完全看不出少了一段。现在直接透传。
- 测速同样改为问内核（借 clash_api），不再只用握手。

## 升级说明

- 装好后内置规则组会自动补进来（配置版本升级到 15）。**只在升级时补一次**：
  你之前手动删过的域名不会回来，自己配的同域名规则也不会被覆盖。
- 测速结果会比以前更容易出现「失败」：这不是新 bug，是以前被握手假象掩盖的
  问题现在暴露出来了。仍失败的节点需要找供应商核对账号授权与出口白名单。
- 流量曲线刚接管的一两秒显示 0 属正常，等第二次采样就有速率了。
