# Network Manager v0.6.1

这是 `v0.6.0` 之后的补丁版本，重点修复 Android 端程序分流和可观测性问题，不改变跨设备配置格式。

## 修复与改进

- Android 程序规则优先于域名规则，命中的应用请求整体走指定代理。
- Android 代理流量使用经所选节点转发的远程 DNS，避免本地 DNS 污染导致应用无法访问。
- 节点端口检测明确标记为“入口检测”，不再将 TCP 入口建连耗时误称为完整代理延迟。
- 设置页动态显示 APK 版本号和内部构建号。
- 完善 Android 连接归属识别、VPN 生命周期与正式 APK 安装流程。

## 版本策略

小范围问题修复只递增补丁版本，例如 `0.6.1` 到 `0.6.2`；只有新增兼容性范围或重要功能时才递增次版本号。

## 发布产物

- `NetworkManager-Android-v0.6.1.apk`：Android 正式签名 APK。
- `NetworkManager-Windows-x64-v0.6.1.zip`：Windows x64 免安装目录包。
- `NetworkManager-Linux-amd64-v0.6.1.tar.gz`：Linux amd64 无界面 WebGUI 服务。
- `NetworkManager-Linux-arm64-v0.6.1.tar.gz`：Linux arm64 无界面 WebGUI 服务。
- GitHub 自动生成的源码 `zip` 和 `tar.gz` 快照。
