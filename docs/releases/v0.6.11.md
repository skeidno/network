# Network Manager v0.6.11

自 v0.6.10 以来共 4 个提交。主线是**界面反馈补齐**与**Windows 双击即提权**，另有一处影响判断的代理出口检测修复。配置格式向后兼容（v11 → v12 只追加新域名）。

## 界面反馈

- **服务器「检查服务 / 部署代理」现在有进行中状态**。此前后端序列化服务器列表时漏掉了部署进度字段，前端读到的永远是空值，于是状态列一直停在「已部署」，点下去像没反应。现在点击瞬间就会显示「检查中」（未部署的显示「部署中」），按钮文案与状态胶囊同步变化，结束或失败后回到真实状态。
- **节点测速点了没反应**，三个原因一起修掉：
  - 前端传的是节点**名字**，后端按数字下标解析，解析不出就退化成 `0` —— 不管点哪个节点，实际都在测第一个节点。现在两端统一，名字和下标都认。
  - 测速期间一直持有状态锁，界面的状态轮询全部阻塞（批量测速最明显：几十个节点 × 3 秒超时），界面像卡死。改为先标记「测试中」立即返回，真正的握手放后台逐个做。
  - 「测试该节点」按钮此前要求内核必须在跑，而测速只是一次 TCP 握手，并不需要接管。已去掉这个限制。
- 状态胶囊新增蓝色「进行中」样式（带呼吸圆点）。

## Windows 桌面端

- **双击即弹 UAC 以管理员运行**。exe 清单改为 `requireAdministrator`，不再需要右键选「以管理员身份运行」或进界面后再点一次「以管理员身份重启」；界面上那条「未以管理员运行」的提示条随之不再出现（逻辑保留作兜底）。每次启动会弹一次 UAC，这是 Windows 对提权程序的硬性要求。
- 兜底：即使清单因任何原因没生效，启动时也会自检，非管理员就用 `runas` 重新拉起自己；UAC 被点「否」时不会误判成功（此前会把当前实例退掉，表现为双击后什么都没发生）。
- **开机自启改用任务计划**。UAC 环境下 Windows 会静默跳过注册表 Run 键里标记为提权的程序，Run 键方案在提权后会失效。现在用 `schtasks` 建登录触发任务（最高权限），并在启动时自愈：配置开着自启但任务缺失就补建一次，同时清掉旧版留下的 Run 键值。

## 代理出口检测

- **修掉「代理出口 IP 与直连相同」**。内核规则第一条是 `PROCESS-NAME,NetworkManager.exe,DIRECT`，本意是让「直连出口」能测到本机真实 IP（否则本程序自己的请求也会被 TUN 送进节点）；但在严格进程匹配下，**本程序发出的代理出口检测请求也命中这条规则，被强制直连**，于是两个出口永远显示同一个 IP —— 与选中哪个节点无关。
- 现在内核配置里多了一个只绑定回环的**检测专用入站**，规则最前面用 `IN-PORT` 把它的流量指向内置节点组，优先级高于进程名规则：直连检测照旧走直连，代理检测强制走节点，互不干扰。检测端口由混合端口确定性派生；万一被其他程序占用，内核只跳过该监听、其余照常启动，不会把网络搞挂。
- 内核还在跑旧配置（没有该入站）时退回混合端口，并明确提示「重启接管后即可精确检测」，不再沿用此前那句会误导人的「接管状态下直连流量也走了内核」。
- **升级后需要重新启动一次接管**：新增的入站不能热重载，配置只在内核启动时加载。

## 分流规则

- 内置代理域名清单从约 60 个扩充到 220+：补齐 Telegram 的图片/下载/CDN 后缀、各社交平台的静态资源域名（Instagram、Threads、Spotify 音频、Netflix 视频、Reddit、LINE 等），新增加密货币交易所、AI 工具、开发者常用 registry/CDN 与流媒体。
- 配置版本 v11 → v12：存量配置**只追加没见过的新域名**，沿用组内现有的去向与开关状态；用户主动删过的条目不会被塞回来，整组被删除也不会重建。

## 产物

- `NetworkManager-Setup-x64-v0.6.11.exe`：Windows x64 安装包（内含 Rust 单文件 exe 与 `mihomo.exe`）。

- `SHA256SUMS.txt`：上述成品的 SHA-256 校验值。

### 关于 Android

`NetworkManager-Android-v0.6.11.apk` 能否随本版提供，取决于仓库是否已配置签名密钥（被 `.gitignore` 排除、不在仓库里，构建环境原本拿不到，`docs/RELEASE_POLICY.md` 禁止用 debug APK 顶替）。流水线已经铺好这条路：四个密钥齐备时会自动产出正式签名 APK 并去掉预发布标记。

| Secret | 内容 |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | `base64 -w0 network-manager-release.keystore` 的输出 |
| `ANDROID_KEYSTORE_PASSWORD` | keystore 口令 |
| `ANDROID_KEY_ALIAS` | 密钥别名（当前为 `network-manager`） |
| `ANDROID_KEY_PASSWORD` | 密钥口令 |

按 `docs/RELEASE_POLICY.md`，必需产物缺任何一件都不得标记为正式发布，因此若 APK 未产出，本版会标记为**预发布**。
