# Network Manager v0.6.13

补丁版，只修一处：**桌面端导入「主机:端口:用户名:密码」不生效**。其余内容与 v0.6.12 相同。

## 问题

导入框里写着「支持 Clash YAML、Base64、分享链接及 主机:端口:用户名:密码」，但把代理商给的

```
163.128.72.103:5774:24A3LUWA16312872103A5774:VXeOGZwy106b
163.128.72.193:7690:24A3LUXA16312872193A7690:X25LE7kCcVDQ
```

粘进去会直接报错、一个节点都进不来。

## 根因：迁移时漏了这条解析

这个格式在 Python 版里有专门的 `parse_authenticated_proxy_line()`，迁到 Rust 时
**函数没搬、界面提示文案搬了**——于是桌面端对外宣称支持，实际只认 `ss://` `vmess://`
`vless://` `trojan://` `hysteria2://` 和 Clash YAML。

Android 端从没这个缺口（`SubscriptionParser.parseAuthenticatedProxyLine` 一直在），
所以只有桌面端会踩到。

## 修复

`rust/src/importers.rs` 补回该解析，规则与旧版 Python / 现有 Android 实现一致：

- 按 `主机:端口:用户名:密码` 切成四段，生成一条 **HTTP 类型**的带认证代理节点，
  名字为 `HTTP Proxy 主机:端口`。
- 主机支持域名与 IP 字面量；IPv6 用方括号写法 `[fd00::1]:8080:user:pass`。
- 密码取第三个冒号之后的全部内容，允许含冒号；用户名与密码都不允许空白字符。
- 端口必须是 1–65535 的数字；主机名按 DNS 标签规则校验，`bad_host!` 这类直接拒绝。
- 校验失败会给出具体原因（第几行、哪一项不对），不再只报「暂不支持」。

顺带守住一个容易踩的坑：**只有含三个以上冒号的行才当代理 IP 解析**。不设这道闸，
整段 Base64 订阅会被逐行判成「代理 IP 格式错误」，把原有的 Base64 兜底挡死。
单测里专门有一条用例锁住这个行为。

## 验证

新增 5 条单测，覆盖真实样例（上面两条）、IPv6 与含冒号密码、各类非法输入、
Base64 订阅不被误伤、分享链接与代理 IP 混排。`cargo test` 全绿（52 + 4 契约测试）。

## 产物

本版由 `.github/workflows/release.yml` 在打标签时自动构建，产物同源（同一个标签、同一个提交）：

- `NetworkManager-Setup-x64-v0.6.13.exe`：Windows x64 安装包（内含 Rust 单文件 exe、`mihomo.exe` 与 `wintun.dll`）。
- `NetworkManager-Linux-amd64-v0.6.13.tar.gz`：Linux amd64 无界面 WebGUI 服务包。
- `NetworkManager-Linux-arm64-v0.6.13.tar.gz`：Linux arm64 无界面 WebGUI 服务包。
- `SHA256SUMS.txt`：上述成品的 SHA-256 校验值。

### 关于 Android

`NetworkManager-Android-v0.6.13.apk` 仍取决于仓库是否配置了签名密钥（被 `.gitignore` 排除，构建环境拿不到，
`docs/RELEASE_POLICY.md` 禁止用 debug APK 顶替）。密钥未配置时 android job 整体跳过，本版标记为**预发布**。
