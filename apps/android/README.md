# Network Manager for Android

Native Android client for subscriptions, proxy nodes, grouped routing rules,
individual and batch latency checks, traffic monitoring, smart node selection,
portable configuration, and VPN takeover. SSH server deployment is not part of
the mobile application.

## Build

Prerequisites:

- JDK 21
- Android SDK 36
- `app/libs/libbox.aar` generated by `scripts/fetch_libbox.ps1`

```powershell
.\scripts\fetch_libbox.ps1
.\gradlew.bat testDebugUnitTest assembleDebug assembleDebugAndroidTest
```

The libbox artifact is pinned to sing-box 1.13.20 and is not committed because it
contains large native binaries. The fetch script verifies every downloaded input.

## Signed release

Create `signing.properties` beside `settings.gradle.kts` with `storeFile`,
`storePassword`, `keyAlias`, and `keyPassword`, then run
`gradlew.bat assembleRelease`. The properties file and keystore are ignored by
Git. Keep the original keystore backed up: Android only permits an installed app
to be upgraded by another APK signed with the same key.

## Device tests

Start an Android emulator or connect a device, then run:

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-21"
$env:ANDROID_HOME = "C:\path\to\Android\Sdk"
.\gradlew.bat connectedDebugAndroidTest
```

The connected tests validate the native direct and smart/urltest configurations,
the node and rules screens, and portable import/export. A final manual smoke test
should grant the Android VPN consent dialog, confirm `tun0` is connected, generate
browser traffic, and stop the VPN cleanly.
