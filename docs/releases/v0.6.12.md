# Network Manager v0.6.12

自 v0.6.11 以来共 20 个提交。主线是**移动端原生界面收尾**、**Android 工具箱与用户档案（数据隔离）**、
**本地 DNS 映射与本地证书自动化**，以及**Windows 安装包不再依赖目标机器环境**。
配置格式向后兼容：`settings.json` 版本 v12 → v13（新增 `local_dns`，`dns_mode` 为追加字段），
旧配置读回时缺失字段回落默认值，非法条目按行清洗。

## Android 界面

- **全站改成移动端原生界面**，不再照搬 PC 面板排版。
- 手机竖屏改回**底部导航**，左侧栏只留给真正的大屏。
- 概览页新增「当前出口」检测（直连 / 代理）。
- 新增本地代理端口，**一个端口同时支持 HTTP 与 SOCKS5**；允许明文 HTTP，否则订阅导入与出口检测会被系统拦掉。
- 节点卡片延迟移到第二行，名字不再被挤成「海…」。

## Android 工具箱（新增）

- 新增「工具箱」页，集中放排障用的诊断能力：**出口 IP 对比**（直连 vs 节点）、**DNS 解析对比**（系统 / DoH）、
  **规则命中预判**、**TCP 端口连通性**、**证书检测**（真实 TLS 握手 + 平台信任库判定 + 证书链详情）、
  **编解码与分享链接解析**（Base64 / URL 编解码、生成 UUID、拆解 `ss://` `vmess://` 链接）。
- 页面组织从「8 张卡片的长滚动列表」改成**宫格目录 + 独立工具页**：顶部搜索框可按标题 / 说明 / 中英别名
  过滤并显示结果计数，按「数据与档案 / 连接诊断 / 证书与 HTTPS / 文本与处理」分组。点进工具是独立页，
  系统返回键回目录而不是退出应用，转屏后停在原页。

## 用户档案（数据隔离，新增）

- 一个档案 = **一整套完全独立的用户数据目录**，用法同浏览器的多个 userdir：节点、订阅、规则、设置写各自
  偏好文件，本地 DNS、本地证书、内核配置与缓存也各一份。默认档案沿用原有路径，升级用户零迁移。
- 支持**新建、分身**（整套复制，含本地证书）、**重命名、删除、切换**；切换时先停止接管，换根后重设内核
  路径并刷新证书与列表。档案列表直接把数据目录显示出来，让「隔离」看得见。

## 档案 × 接管 App 名单（新增）

- 每个档案可绑定一份「**只接管哪些 App**」的白名单，对应「只有一两个 App 要走代理」的场景：九宫格列出
  已安装应用（真实图标、可搜索、可多选），选好 App 再起名建档案；已有档案进详情页可随时调整。
- 名单非空时下发到 sing-box `tun` 的 `include_package`，经 libbox 传到 `VpnService.addAllowedApplication`。
  名单为空表示接管全部应用（保持原行为）——空名单**不会**写出 `include_package` 字段，因为写空数组等于
  谁都不接管，语义正好相反。名单归一化时剔除本应用自身包名。

## 本地 DNS 映射（双端）

- 设置里一行一条 `域名 IP`（字段顺序随意、`#` 注释、上限 200 条）。Android 端写进 sing-box 的 hosts DNS
  服务器，桌面端写进 mihomo 的 `hosts` 表，两端同一套语法与校验。IPv6 允许粘 `[fd00::9]` 这类 URL 写法，
  落盘统一去掉方括号。
- 桌面端映射到**内网地址**的域名会额外生成一条 `DOMAIN,<域名>,DIRECT` 规则：TUN 开着嗅探且
  `override-destination` 时，规则看到的是域名，兜底的 `IP-CIDR` 会漏掉。没有配置映射的用户，生成的配置
  与改动前逐字节一致。
- `*.baidu.com` 表示 **baidu.com 本身 + 它的所有子域**。两端内核能力不同，同一语义各自翻译：mihomo 用
  `+.baidu.com`（`*.x` 在 v1.19.x 里只匹配子域、不含裸域，访问裸域会漏）；sing-box 走 DNS 规则的
  `predefined` 动作，每个通配条目生成两条规则（精确的管裸域、带 `*` 的管子域）。`*.com` 这类会接管整个
  顶级域的写法在校验层拒绝。

## 本地证书自动签发（双端）

- 按当前映射集合自动签一套 CA + 叶证书：SAN 覆盖全部映射名（通配写法补上裸域、字面量 IP 进 `iPAddress`）。
  CA 3650 天只建一次；叶证书 **397 天** —— 超过 398 天时 Chrome Root Store 会直接拒绝私有根签发的证书
  （`ERR_CERT_VALIDITY_TOO_LONG`）。名字变更、文件缺失或剩余不足 30 天时自动重签。
- 叶证书带 AKI、EC 证书不声明 Key Encipherment，以满足 Python `ssl` / `openssl -x509_strict` 的严格校验。
- 桌面端一键导入当前用户根证书库（走系统自带 `certutil`，无需管理员权限）；Android 端导出后装入系统信任库。
  另附 `scripts/local_https_flask.py`，复用同一份 CA 把映射域名跑成局域网 HTTPS 站点。

## 桌面端 DNS 应答收窄

- **fake-ip 过滤名单从 5 条扩到 28 条**：内网后缀、NTP 校时、系统连通性探测、验证码、快速登录域名 ——
  这些一律需要真实 IP，拿到 `198.18.x.x` 会让托盘误判网络状态、验证码直接拒绝。
- 增加 `respect-rules` 与 `direct-nameserver` / `proxy-server-nameserver`：直连域名走国内 DoH 解析，
  节点域名固定用国内 DNS 解析，避免「连节点才能解析节点域名」的死循环。
- 新增「**DNS 兼容模式**」开关（`dns_mode`：`fake-ip` | `redir-host`）。开启后所有域名返回真实 IP、域名
  匹配交给连接嗅探，用于过滤名单覆盖不到、一开接管就异常的场景。该设置不热重载，改完需重新接管；
  旧配置没有这个字段时回落 `fake-ip`。

## Windows 安装包

- **自带全部运行时依赖**，不再依赖目标机器环境：
  - 通过 `.cargo/config.toml` 对 MSVC 目标开启 `+crt-static`，静态链接运行时后产物导入表里不再有
    `VCRUNTIME140*.dll` 与整组 `api-ms-win-crt-*`，干净系统（LTSC / Server / 精简装机）上不会因为缺
    VC++ 2015-2022 可再发行组件而直接弹窗退出。
  - 随包分发 `wintun.dll`（与 `mihomo.exe` 同级；mihomo 按 DLL 名加载，Windows 搜索顺序里可执行文件所在
    目录最优先），版本与 SHA-256 钉在 `vendor/wintun.version.json`。
  - 安装器检测 WebView2 运行时，缺失时用内置的 Evergreen Bootstrapper 静默安装（这一步需要联网下载运行时），
    引导器本身不落盘。
- 安装包在目标机器上的硬依赖只剩 WebView2 运行时一项，README 新增「安装包在目标机器上需要什么」一节。

## 桌面端其他修复

- 关到托盘后**接管核心自愈**，代理不再悄悄失效。
- 窗口尺寸 / DPI 变化后显式同步 WebView bounds，页面不再被右侧裁掉。
- 窄屏下工具栏换行，页面不再被撑出横向滚动；修复「复制节点」不生效的问题。

### 关于 Android

`NetworkManager-Android-v0.6.12.apk` 能否随本版提供，取决于仓库是否已配置签名密钥（被 `.gitignore` 排除、
不在仓库里，构建环境原本拿不到，`docs/RELEASE_POLICY.md` 禁止用 debug APK 顶替）。四个密钥齐备时会自动
产出正式签名 APK 并去掉预发布标记。

| Secret | 内容 |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | `base64 -w0 network-manager-release.keystore` 的输出 |
| `ANDROID_KEYSTORE_PASSWORD` | keystore 口令 |
| `ANDROID_KEY_ALIAS` | 密钥别名（当前为 `network-manager`） |
| `ANDROID_KEY_PASSWORD` | 密钥口令 |

按 `docs/RELEASE_POLICY.md`，必需产物缺任何一件都不得标记为正式发布，因此若 APK 未产出，本版会标记为**预发布**。

### 已知边界

- 浏览器 / 系统的「安全 DNS / 私人 DNS」会绕过本地 DNS 映射表，属于预期行为（设置页有说明）。
- 「DNS 兼容模式」与「本地 DNS 映射」保存后都不热重载，需要重新接管才生效（界面有提示）。
- 用户档案隔离的是**本应用自己的数据**。第三方应用的 `/data/data`、登录 token、`android_id`、IMEI / 序列号
  不在覆盖范围内 —— 那是 Android 按 uid 划分的系统沙箱，VPN 类应用无权改动；真要给某个应用多份数据，
  需使用系统多用户 / 工作档案或 ROM 自带的应用分身。
- Linux 侧仍只有 CI 冒烟，TUN 接管、订阅刷新、节点测速、SSH 部署未在真机验证。
