# Network Manager v0.6.2

这是 Windows 分发方式补丁版本，不改变配置格式和代理规则行为。

## 改进

- 新增标准 Windows x64 安装程序，不再需要手动解压目录包。
- 默认安装到当前用户目录，安装过程无需管理员权限；启动 TUN 接管时主程序仍会请求管理员权限。
- 自动创建开始菜单入口，并默认创建桌面快捷方式。
- 支持同一安装目录覆盖升级和 Windows“已安装的应用”标准卸载。
- 卸载时保留用户配置，避免升级或重新安装后丢失订阅与规则。

## 发布产物

- `NetworkManager-Setup-x64-v0.6.2.exe`：推荐使用的 Windows 安装程序。
- `SHA256SUMS-Windows.txt`：Windows 发布文件的 SHA-256 校验值。
- GitHub 自动生成的源码 `zip` 和 `tar.gz` 快照。

安装程序尚未配置商业代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Release 下载并使用 SHA-256 文件校验完整性。
